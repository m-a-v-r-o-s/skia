# SKIÁ image generation prompts

15 images, generated in ChatGPT and now stored in this folder as **lossless
WebP masters named `1.webp` to `15.webp`** - the number matches the heading
number below, and each heading also names the `site/img/` file it feeds.

These are the only full-frame originals. What ships in `site/img/` is cropped to
each layout frame (the hero loses ~14% of height to reach 16:9, the pieces ~11%,
`shop-tinos` about a third), so re-crop from here, never from `site/img/`.

## How they were run

- GPT Image only outputs three shapes: square, portrait (2:3), landscape (3:2).
  Each prompt ends with the one to use. Do not try to force 16:9 or 3:4.
- **Run each group in a single chat**, in order. The models and the studio set
  need to stay consistent within a group. For every prompt after the first in a
  group, paste the prompt then add: `Same model, same studio, same lighting as
  the previous image.`
- Group A: hero (alone). Group B: 2-6 plus 9-10 (same male model).
  Group C: 7-8 (garment only, no model). Group D: 11-15 (same female model).
- Save at the largest size offered.
